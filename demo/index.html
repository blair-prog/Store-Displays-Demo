AMKO Displays: three visual concepts

Static mockups for the redesign discussion, built from the SmartSites x Store Display kickoff call (13 Nov 2026) and the live amkodisplays.com. Each concept uses the same sample content so the client compares layout and feel, not copy.

Read this first. These are not the real Shopify themes and not a build. They are HTML/CSS mockups styled after the layout feel of Concept, Release and Prestige. All prices, photos, stats, reviews and the gondola builder are SAMPLE or CONCEPT. The real build happens in Shopify once the client store exists.
